# Asset credits & licenses

## App icon & splash mark

The app icon, Android adaptive icon, web favicon, and splash logo all use the
**`book-bible` (`mdi:bible`) icon from Material Design Icons** by the
Pictogrammers community.

- Source: https://pictogrammers.com/library/mdi/icon/book-bible/
- License: **Apache License 2.0** — free for commercial use, modification, and
  distribution. No visible attribution is required; this notice satisfies the
  license's notice requirement.

The mark is recolored (warm gold `#FFC25A`) and composited on a brand gradient
(`#2A1B2C → #130E11`). It is regenerated by `scripts/build-app-icons.py`, which
fetches the source icon via the Iconify API and renders every required PNG size.

To regenerate or swap the icon (e.g. try `ph:book-open-text-fill`, MIT, or
`mdi:book-cross`, Apache-2.0): edit `PREFIX`/`NAME`/`GOLD` in
`scripts/build-app-icons.py`, then:

```bash
python3 scripts/build-app-icons.py     # writes to ./out
# review ./out, then copy the app-icon-*.png into assets/images/
```

Requires Python with `cairosvg` and `Pillow`.

## Other bundled images

`logo*.png` and `welcome-face*.png` are original Ignite boilerplate demo assets
(Infinite Red), now only referenced by the unrouted `WelcomeScreen` — safe to
remove. `sad-face*.png` is still referenced by the `EmptyState` component, so
leave it (or replace it if you use `EmptyState` anywhere).
